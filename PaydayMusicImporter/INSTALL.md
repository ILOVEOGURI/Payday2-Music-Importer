# Install the mod

1. Install SuperBLT and BeardLib for PAYDAY 2.
2. Copy this entire folder to `PAYDAY 2\mods\PaydayMusicImporter`.
3. Run `Start-Helper.cmd` and leave its window open.
4. In PAYDAY 2, open **Options → PAYDAY 2 Music Importer** and choose **Open YouTube picker**. The first launch downloads standalone Chromium. Selecting a YouTube video automatically queues the download, uses its page title as the track name, and returns Chromium to YouTube's home page.
5. Or paste a YouTube link, enter a name, and choose **Queue download**.
6. After the helper reports success, restart PAYDAY 2 and select the new menu music.

The helper installs its download tools in `%LOCALAPPDATA%` and does not need administrator privileges. See the project `README.md` for details and troubleshooting.
