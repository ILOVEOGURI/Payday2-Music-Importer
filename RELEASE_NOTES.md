# PAYDAY 2 Music Importer 1.0

First public release.

- Import menu music through the in-game YouTube picker or a pasted video URL.
- Automatically start the PowerShell helper when PAYDAY 2 loads the mod.
- Install through the standalone Windows installer.
- Restart the game through the in-game Steam restart button.

Requires SuperBLT and BeardLib. The installer detects missing prerequisites and provides setup links.
